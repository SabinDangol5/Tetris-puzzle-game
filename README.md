# Tetris Puzzle Game

A classic **Tetris puzzle game** built with plain **HTML, CSS, and JavaScript**. Play directly in your browser with no installation required.

![Gameplay Screenshot](assets/screenshots/gameplayScreenshot.png)

## 🎮 Features

- Classic Tetris gameplay.
- 7 Tetromino shapes: I, J, L, O, S, T, Z.
- Line clearing and scoring system.
- Level progression with increasing speed.
- Display for next piece, score, lines, and level.
- Keyboard controls with optional pause and reset.
- Single-file implementation for easy hosting.

## 🕹️ Controls

| Key | Action |
|-----|--------|
| ←   | Move left |
| →   | Move right |
| ↓   | Soft drop |
| ↑   | Rotate |
| Space | Hard drop |
| P   | Pause |
| R   | Restart |

## ⚡ How to Play

1. Open `tetris-puzzle-game.html` in a web browser.
2. Use the keyboard to move and rotate Tetrominoes.
3. Complete horizontal lines to score points.
4. Game ends when pieces reach the top of the board.

## 📦 Tech Stack

- **HTML5** for structure.
- **CSS3** for styling.
- **JavaScript** for game logic.
